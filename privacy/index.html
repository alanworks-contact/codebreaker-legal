수집·공유하는 정보

이 버전은 회원가입, 광고, 인앱 결제, 분석 SDK, 원격 게임 서버를 사용하지 않습니다. 게임 앱은 개인정보를 수집하거나 외부 서버에 전송·판매·공유하지 않습니다.

기기 안에 저장하는 정보

진행도, 기록, 모듈 해금, 수동 메모와 설정, 약관 동의 및 방침 확인 버전·시각을 기기 내부에 저장합니다. 알림을 선택하면 알림 사용 여부, 기기 내 무작위 값, 마지막 전달 날짜와 다음 예정 시각도 기기에만 저장합니다. 운영자는 이 정보에 원격으로 접근하지 않습니다. 앱 데이터 삭제 또는 앱 삭제로 이 정보가 지워질 수 있으며 별도 계정 동기화나 복구를 제공하지 않습니다. 앱은 Android 자동 백업을 사용하지 않도록 설정합니다. 다만 이용자가 직접 수행하는 기기 이전·별도 백업과 운영체제 또는 기기 제조사의 처리는 앱 자체의 서버 수집·전송과 구분되며, 해당 공급자의 설정과 정책을 확인해 주세요.

선택 알림 권한

Android 13 이상에서는 사용자가 알림 받기를 선택한 경우에만 알림 권한을 요청합니다. 알림은 기기에서 하루 최대 한 번 점심 또는 저녁 시간대에 예약하며 원격 푸시 토큰이나 서버 등록을 사용하지 않습니다. 권한을 거부하거나 나중에를 선택해도 게임을 이용할 수 있습니다. 설정의 플레이 알림을 끄면 이후 예약을 취소하며, 시스템 설정에서도 권한을 바꿀 수 있습니다.

앱은 연령이나 연락처를 요구하지 않습니다. 모든 이용자의 게임 정보는 같은 방식으로 기기 내부에서 처리됩니다. 기기의 화면 잠금과 운영체제 보안 업데이트를 권장합니다. 문의 이메일에 이용자가 직접 포함한 정보는 문의 답변에 필요한 범위에서만 사용하고 목적이 끝나면 삭제합니다.
